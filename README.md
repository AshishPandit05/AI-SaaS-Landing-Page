# AI SaaS Landing Page

A modern, responsive and visually engaging SaaS landing page for an AI-powered startup, built with React and Tailwind CSS.

## 🚀 About The Project

This project is a frontend development implementation of an AI SaaS landing page. It showcases a modern website design for an AI-powered software product, focusing on clean UI, responsive layouts, and smooth user interactions.

The goal of this project is to build a professional SaaS landing page while improving my frontend development skills.

## ✨ Features

- Modern and clean SaaS design
- Fully responsive layout
- Reusable React components
- Smooth navigation between sections
- Interactive UI elements
- Modern typography and styling
- Mobile-friendly interface

## 🛠️ Tech Stack

- **React.js** – Frontend library
- **Tailwind CSS** – Utility-first CSS framework
- **React Router DOM** – Client-side routing
- **Lucide React** – Icons
- **JavaScript (ES6+)** – Programming language
- **Vite** – Development and build tool

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/AshishPandit05/AI-SaaS-Landing-Page.git
```

### 2. Navigate to Project Directory

```bash
cd ai-saas-landing-page
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
